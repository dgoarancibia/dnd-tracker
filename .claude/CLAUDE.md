# Diego

## Antes de actuar
- Si es ambiguo o implica decisión arquitectónica → pregunta.
- Si es claro → procede directo.
- Si algo falla → arréglalo solo, salvo que cambie arquitectura.

## Comunicación
- Español.
- Máximo 2-3 líneas.
- Sin saludos ni resúmenes. Qué hiciste. Punto.
- Solo elabora si pregunto o si algo se rompe.

## Código
- Decide el stack según el problema, salvo que yo indique otro.
- No muestres código completo salvo que lo pida.
- Refactoriza si ves algo mejorable — avisa qué y por qué en una línea.

## Git
- Commit automático al terminar cada tarea.
- Mensaje corto en español.
- No hagas push automático.

## Contexto
- Sin asumir nada del proyecto — lo doy al inicio de cada sesión.
- Si el contexto es insuficiente → pregunta antes de proceder.
