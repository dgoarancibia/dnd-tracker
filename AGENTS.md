# AGENTS.md

Instrucciones para agentes de código (Codex, Claude Code, etc.) en este repo.

1. Lee primero `agent_docs/CONTEXTO.md`: arquitectura, cómo publicar, pruebas y reglas que no se negocian.
2. Si vienes a **probar** la app, sigue `agent_docs/PRUEBAS_CODEX.md`.

Reglas cortas:
- Responde en español latino.
- No hagas `git push` ni cambies la configuración del remoto.
- La app **nunca tira dados**: los comandos van a Roll20.
- No uses aidedd.org como fuente de reglas (sirve reglas 2014).
- Antes de cambiar UX/UI, pregunta.
